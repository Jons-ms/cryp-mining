# Граюбельний прототип (один HTML-файл)

`index.html` — повна гра в одному файлі: ферма 4×4, магазин, біржа зі спільним курсом, Подіум, особисті дані.
Відкривається в браузері без сервера (прогрес у localStorage). Розрахунки виконує браузер, тому прототип
не захищений від підробки. Захищена версія з серверною економікою — у папках `server/` і `public/`.
